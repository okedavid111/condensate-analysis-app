# Changelog

All notable changes to the public software are documented here.

## 1.0.0 — 2026-11-16

- First public, versioned release.
- Added cross-platform ROI review, cropping, and channel-cleaning workflow.
- Added automated Fiji/ImageJ JACoP Pearson and directional Manders analysis.
- Added Fiji watershed and Analyze Particles condensate count/size analysis.
- Added manual ROI-based partition-coefficient analysis.
- Added fixed-cell MS2/condensate intensity, distance, QC, and Excel output.
- Added saved per-image parameters, thresholds, channel roles, and audit previews.
